
CyberLex CR
Diccionario Digital de Seguridad y Cultura Tecnológica
CyberLex CR es una aplicación de escritorio desarrollada en **Java y Java Swing**, como proyecto académico de Ingeniería en Seguridad Informática en la Universidad Fidélitas.
Objetivo
Facilitar la comprensión de términos utilizados en redes sociales, Internet y ciberseguridad, especialmente para adultos mayores y personas con poca familiaridad con la tecnología.
Funcionalidades
- Registrar nuevos términos y sus definiciones.
- Consultar palabras mediante un buscador.
- Guardar y recuperar diccionarios mediante serialización.
- Ordenar términos alfabéticamente.
- Actualizar definiciones de términos existentes.
- Utilizar una interfaz gráfica sencilla e intuitiva.
Tecnologías utilizadas
- Java
- Java Swing
- Programación orientada a objetos (POO)
- ArrayList
- Serializable y Comparable
- Manejo de archivos y excepciones
- Apache NetBeans IDE
Ejemplos de términos
- **Phishing:** Técnica utilizada para engañar y obtener información confidencial.
- **Troll:** Persona que publica mensajes provocadores en Internet.
- **Hater:** Persona que expresa críticas hostiles u odio en medios digitales.
- **Malware:** Software diseñado para causar daños o realizar acciones no autorizadas.
- **Ransomware:** Malware que bloquea o cifra información para exigir un rescate.
Cómo ejecutar
1. Descargar o clonar el repositorio.
2. Abrir el proyecto en Apache NetBeans.
3. Configurar un JDK compatible.
4. Ejecutar la clase `CyberLexCR.java`.
5. Utilizar el menú **Opciones → Nuevo Diccionario** para registrar términos.
